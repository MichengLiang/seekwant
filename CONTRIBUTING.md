# Contributing

seekwant is maintained by its core team as a source-available product project,
not as a community-governed open source project.

Public source access supports review, reproducibility, issue reporting, and
noncommercial use. Substantive external contributions require prior maintainer
approval and may require a signed Contributor License Agreement.

## Issues and Discussion

Bug reports, factual problem descriptions, and focused reproduction notes are
welcome when the repository is public.

Please avoid submitting implementation patches before a maintainer confirms that
the contribution fits the project direction and contribution requirements.

## Pull Requests

Opening a pull request does not imply that the contribution will be accepted,
reviewed, maintained, or governed by public consensus.

Maintainers may close pull requests that:

- arrive without prior approval for substantive code or documentation changes;
- conflict with the project license, commercial strategy, or product direction;
- lack tests for user-visible behavior;
- introduce unclear ownership, third-party rights, or confidentiality concerns.
